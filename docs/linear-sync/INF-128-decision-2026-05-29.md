## INF-160

Client integration guidance:
- Use `GET /api/attendance/today-locations` for the hero map/current checked-in location snapshot.
- Do not pass `period`, `from`, or `to` to today-locations; it is not range-aware.
- Use `?limit=<positive integer>` only for display cap control.
- Treat `authority: context_only` as a UI/data-context signal, not final attendance evidence.
- Use attendance records and reporting endpoints for final attendance state and historical analysis.
