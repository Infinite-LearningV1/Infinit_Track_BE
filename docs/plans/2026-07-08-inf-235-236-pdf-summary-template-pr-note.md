## INF-235 — Summary correctness

Changed the personal attendance report summary to expose UI-ready counted-day semantics:

- `attendance_rate`
- `attendance_rate_percent`
- `attendance_rate_label`
- `attendance_rate_denominator`
- `total_present`
- `total_absent`
- `total_counted_days`
- `on_time_days`
- `late_days`
- `alpha_days`
- `total_work_hours_label`
- `expected_working_days_label`
- `expected_working_days_note`

Attendance rate formula:

```text
total_present = attended_days
total_absent = alpha
total_counted_days = total_present + total_absent
attendance_rate = round((total_present / total_counted_days) * 100)
```

When counted days are zero, rate remains `null` / `N/A` safely.

Expected working days remains unavailable because official denominator is not verified.

Alpha row rendering remains safe:

- `--:-- - --:--`
- no misleading formatted work duration
- raw work hour null

## INF-236 — PDF template/layout

Updated the PDF renderer from line-by-line report text into a structured official document layout:

- brand/report header
- `PDF Ready • Personal report` badge text
- identity block: full name, NIP/NIM, role, position, division if present
- metadata: period, generated on, generated by, data source
- summary metric section
- attendance status distribution
- work mode distribution
- monthly attendance history table-like rows
- footer with generated-by, timestamp, page number

Per user direction, no body Source Note section was added.
